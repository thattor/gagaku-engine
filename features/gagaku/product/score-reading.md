# 五常楽急の原譜読解と実音声（2026-09-30）

1932年三管譜から、冒頭5拍点の三管stem・合奏30秒と、笙の本体32拍点の読解音声192秒を作った。実音声は既存の自前物理生成器を使う。龍笛のレジスターと装飾、拍内配置、手移りは未検証を含むため、音声は**読解プレビュー**であり、完成した五常楽急の演奏ではない。止手と有効な終了境界は未確定で、製品M/EはBLOCKEDを維持する。

以前のREADMEの「1932 c5–6が凡例」は誤りだった。目録と楽器図であり、運指・拍節の説明は上記の別箇所にある。1932三管の序（c3–4）は拍点を赤で統一した説明を含む。巻末の確認画像は鳳笙c41–43、竜笛c45–46、篳篥c44–45で、最終楽曲/奥付だった。巻全体に止手が存在しないという網羅的結論にはしない。

### 音高だけ確かめられた箇所

笙の冒頭は **十→行→下→十→乙→乙→下→十**。単音の竹名として鳴らさず、合竹表の閉孔を発音管へ展開する。例えば十は下・十・行・七・上・八、行は行・七・上・八・千。1894 c30の曲を1932 c14–15と別に読み、単純な合竹30箇所が一致することを目視で照合した。残り2箇所（第三行第六拍点、第四行第三拍点）は上下に重ねた字を単一の通常合竹へ潰さず保留した。

篳篥の冒頭「テエルレエ」は、小字の**上→一→上**を使う。1894 c10右の表は上＝双調、一＝下無、四＝平調を示し、c10左の口伝解とc14左の曲でもこの運指順を照合できる。現行の実音域との対応はG5→F#5→G5とした。大字のエを笙の「工」や独立音高として読まない。第一行第六拍点「ハア」の小字ノの発音・息制御は未確定なのでプレビューに含めない。

龍笛は小字の干＝平調、五＝下無、中＝盤渉、六＝壱越を指遣い表・音字表で追える。しかし同じ運指から複数のオクターブを出せる。今回のE5/D6/B5/F#5/G5の配置は**解釈候補**で、セメ/フクラの演奏全体との照合は済んでいない。由は前句を重ねる指示、くは運指で打つ指示を含む。これらを自動的に新音符へ変換してverifiedにしない。

笙の実音域・合竹音高とA430、龍笛の同一運指の複数レジスターは [Stanford笙](https://gagaku.stanford.edu/en/woodwinds/sho/)・[龍笛](https://gagaku.stanford.edu/en/woodwinds/ryuteki/) の解説と図を目視で照合した。利用は音高・奏法の事実の参照だけであり、図や録音を制作音声に入れていない。

### 拍・奏法と自前の演奏設計

各行8個の赤い主拍点、早八拍子・拍子八の文字は確認できる。1894 c11の小拍子は唱歌内部の打ち方を説明する。しかし三管全イベントの拍内位置を原資料と独立に照合し終えていない。プレビューでは主拍点を4分割し、1分割1.5秒、A430の平均律近似、立上り0.15秒・減衰0.25秒とした。これらと装飾のoffsetは `preview_design` で、歴史的なテンポ/音律/奏法の実証ではない。

笙c13–14の図は吸吹、弱→強、気替と手移の関係を示すが、個々の合竹間の全指順までは確定していない。今回の音声は合竹を区切って鳴らす還元で、伝統的な手移の実装・検証とは扱わない。塩梅、連続気圧、レジスターに応じた音色も未受入。モデル再同定やQの総作り直しへは戻っていない。

## 初度・二返・止手

1932竜笛c15右の初度用之は別列にあり、1894竜笛c14には後度用之がある。局所置換の開始・終了、主列との接続を先に確定する必要がある。三管c15の第二・第四行末の二返は印字を確認したが、戻る場所と、局所二回演奏か全体反復かの確定を終えていない。音声は初度/二返を実装済みと表示しない。

平調止手の三管音列・入口と許される出口は未取得。1932の本文だけでなく序・前付・合竹表・巻末、1894の運指/拍節/手移説明と対象曲を探索した。[Stanford形式説明](https://gagaku.stanford.edu/en/theory/form/) と [京都市立芸大の一次解説](https://rijtm.kcua.ac.jp/archives/takuwa20121013openschool.html) は止手の役割を説明するが、この曲の三管イベントを与えない。現代教材の止手収録は存在確認に留まる。

次の探索先は1923『独習雅楽選譜』pid1185419の許可された本文閲覧、宮内庁明治撰定譜/国書の実際の止手譜、PDの直接的教則資料。1923版はcatalogだけ取得でき、本文の閲覧制限を迂回していない。別版を対象版と無条件に混ぜず、移植する読解規則と曲の差異を照合する。断片のフェード/自然終了を止手へ昇格させない。

## 再生成と確認

repo rootから、Python 3.12標準ライブラリだけで実行する。診断fixtureは変更していない。

```sh
python3.12 -m unittest discover -s features/gagaku -t . -v
python3.12 -m features.gagaku.product.fetch_score_sources --output-dir output/gagaku-continuation/pages
python3.12 -m features.gagaku.product.score_audio --preview --output-dir output/goshouraku-score
python3.12 -m features.gagaku.product.verify_score output/goshouraku-score
python3.12 -m http.server 8766 --bind 127.0.0.1 --directory output/goshouraku-score
```

`http://127.0.0.1:8766/player.html` に合奏・三管stem・笙本体の音声がある。`--preview` を省くと未検証の終了を含む製品生成は拒否される。hash・生成器・gainはmanifest、発音数/PCM/coverageの確認はinspectionに残る。これらのプログラム検査は音高の原譜照合・音色・Uを代行しない。

原資料のPDM表記は権利台帳に別記し、診断用と実曲読解用のallowlistを分けた。制御と音声は自前生成。配信音声・参照録音・サンプル・残響応答は混入していない。

今回の検査は雅楽回帰27件PASS、20枚の原譜画像SHA一致、別ディレクトリへの再生成で5 WAV・3 raw gzipバンク・eventログのbyte一致。ブラウザで5音声の読込と合奏の再生進行を確認した。全30秒の再生終了、主観的試聴、完成品の音色・運用は未確認。結果と音声hashは `score-evidence.json` に固定した。
