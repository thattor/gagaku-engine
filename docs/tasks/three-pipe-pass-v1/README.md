# 初度字形の採用と本体反復運用候補

PR8 `three-pipe-body-candidate` HEAD2136c7cf851b14fb052b4e3ccbbe4ff3dd857444をbaseとする依存Draft。96秒本体を2回、192秒で生成する。既存WAVを繋ぐのではなく、元event列を展開し、反復境界で共通笙管を保持した1本の波形を作る。1011終了要求の候補境界選択と実WebAudioの終了要求を検査する。verified出口/止手や製品Eの達成には算入しない。

## 資料と採用範囲

1932龍笛NDL1194354 c15最右「初度用之」2赤点は、トロホ（中→夕→く）、ルイ（五→上）。隣の共通L2はチラハ（同小字順）、ルイ（同小字順）。1894龍笛NDL855852 c14右「後度用之」のチイラハ/ルウイはこの対比を支持する。初回だけ初度別列の唱歌を選び、次回は共通列を選ぶ。ただし現在の候補ではMIDIも等分割時刻も同じなので、音声差はない。未知の装飾差を創作しない。L2.P2後に共通P3へ戻すのは作者採用解釈、直接矢印は未確認。くの打指は引き続き省略する。

篳篥の二返表示と龍笛L3末尾の返二は、共通の戻り位置を直接与えない。旧score-readingの「三管第二・第四行末」一括表現は龍笛に当てはめない。今回の32点全体反復は**作者の運用用採用**であり真正の二返を実装済みと表示しない。AABBなどの構造を推測だけで採用しない。龍笛ソロ音頭と付所の対象譜上の時刻も未確定、今回も全合奏開始候補のまま。

1932三管c3/c4の序6画像、1894龍笛c10/c11と篳篥c11の拍節説明を限定確認したが、曲固有の三管止手音列/入口/出口は確定できなかった。Stanfordの[演奏形式解説](https://gagaku.stanford.edu/en/theory/form/)および京都市立芸大の[講座報告](https://rijtm.kcua.ac.jp/archives/takuwa20121013openschool.html)はソロ入口とコーダの役割の参照だけとし、別曲の終了句を制作に流用しない。研究ブログの古い舞楽吹止式の翻訳は一次画像未照合・曲/版適用未確認につき採用しない。限定確認範囲で未取得という結果であり、巻全体/公開資料すべてに不存在と断定しない。

元画像URL、SHA、位置、独立字形照合と採用仮説は `three-pipe-pass-v1.json` に保存。音色/音域/テンポ等のPR8未検証を継承する。

## 接続と終了

笙は192秒eventへ展開後、同管の境界隣接spanを連結し波形位相と保続を維持する。管の集合が変わる部分は既存自前制御で除去/追加する。旋律は通常音字で再発音し、既存特殊継続は保持する。attack .15/release .25秒は作者値で実器測定ではない。

再生は192秒で自動終了。終了要求が95.75秒までなら96秒、以後は192秒の候補境界へ進む。前者は95.75..96秒でlinear gainを下げる。減衰開始後の要求で96秒を選ばず、全0.25秒を確保する。後者は生成音声の末尾releaseを使う。0.08秒のWebAudio開始猶予、48kHz固定。停止時刻、演奏state、候補/未verifiedをログへ記録する。早期96秒WAVは同じ候補gainで別保存、元192秒WAVを保持する。

これは試作品を安全に終える運用境界で、音楽的に検証済みの出口でも止手でもない。正しい三管止手の譜面または許諾済み直接資料と入口対応が必要。今すぐ本人試聴や歴史譜完全解読を全開発のgateにしない。R/M/A/E/P/Uは今回も製品PASSにしない。
