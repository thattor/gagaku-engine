# 三管抜粋の連続試聴と終了要求

PR6の第1行24秒音声を、連続試聴・終了要求・人工減衰による終了まで動かす。依存は未merge PR6、commit `5b438e3a79b2a034aceb6f46d965871b439292ee`。旧WAV・譜面fixture・厳格読解のBLOCKED判定は保存する。

## 本体三管化の不足

保存済みfixtureは笙32主拍点、龍笛8、篳篥8。龍笛・篳篥の第2〜4行、計48点の音高eventは存在しない。32×三管を生成済みとは表示しない。

既存 `score-sources.json` の20画像を再取得しhash一致を確認。1932『竜笛譜』NDL1194354 c15右印刷18と『篳篥譜』NDL1192011 c15右印刷18を画像で確認した。三つの本体列、竜笛の初度用之の別列、二返の印字は見える。しかし各主拍点内部の打ち・延引・運指と音域、別列の主列への入口・出口は未転記・未照合。画像の存在確認だけを演奏eventの確定にしない。下記48点を欠落IDとしてinspectionへ列挙する。古い読解報告の未検証を保持し、歴史譜の完全解読を試聴用運用のgateにはしない。

このstepで採用するのはPR6の第1行だけである。全本体化は、これら48点の指字/音域/必要な記号解釈を資料位置付きで採用できるまで未実装。止手は三管の音列と入口・出口の直接根拠が不足し、人工減衰で置換してverifiedにしない。

## 動作と検査

24秒音声の接続には0.4秒の線形重ね合わせを使う。次の開始間隔は23.6秒で、重ね合わせ区間では前音声が1→0、次が0→1となる。これは試聴用の自前制御であり、伝統的反復や音楽的自然さの認定ではない。

終了要求時にすでに始まった抜粋の本数を固定し、その末尾まで再生する。先読みで予約されただけの次音声はキャンセルする。最後の音声は他の抜粋へ減衰せず、元PCMの終端前0.25秒減衰を使う。待ち時間は最大24秒。`playing → finish_pending → ended` とし、`verified_exit`/`tomede` は全経路false。緊急停止・製品Eの経路とは分ける。

0〜600秒の固定seed1000件と83境界ケース（全25接続の直前・正時・直後を含む）を検査する。7秒・23.7秒・300秒で終了要求した実音声を作り、300秒例は307.2秒で終える。5分例は合奏と3stemを保存する。PCM形状、clip、端点0、内部100ms無音、全接続境界のsample差分を検査し、再構成したPCM hashも一致させる。閾値は旧三管版の数値限界を保持する。5/10/20分の実曲運用受入を達成したという意味ではない。

ブラウザの入力はPR6のMac/Linux生成合奏WAVのSHA256 allowlistと一致したものだけ受け付ける。任意の第三者録音を制作経路へ渡さない。ブラウザは同じ48kHz PCM16をdecodeし、同じ0.4秒線形gainをWebAudioの時刻で予約する。タイマーは次音声の予約と状態表示だけに使う。メインスレッドが長時間停止した場合の欠落は保証しない。10分で自動的に終了要求する。短い開始・終了試験を実ブラウザでも行い、WebAudioの音声進行と終了記録を確認する。ユーザー音色評価Uは別で未実施。
