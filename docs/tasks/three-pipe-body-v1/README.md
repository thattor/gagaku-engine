# 三管本体4行の採用解釈候補

PR7 `three-pipe-excerpt-operation` の上に依存するDraft。第1行の繰り返しを拡張せず、32主拍点×3秒=96秒で各管の本体4行を1回通す。龍笛・篳篥の残48点を1932 c15右頁から転記候補として追加する。原資料画像のSHAと採用解釈は `three-pipe-body-v1.json`、実時刻は生成 `body-events.json` に記録する。笙は既存32点の1932版（工は下）を使い、残24点の未再照合を保持する。

## 採用解釈と限界

通常小字→調名は1894年の音字表を参照する。龍笛のテを平調、丁をc10音字表の上無として扱う（c9開閉表の神仙表示とは差があるためc10を採用）。篳篥九は神仙。洋楽音名の概略対応は[日本三曲協会](https://www.sankyoku.jp/term.php)の上無=C#、神仙=Cを用いる。これは音高クラスの対応で、平均律のHz・オクターブ検証ではない。小字くは打指記号で、通常音高字ではないため、この候補では打指を省略し直前音を継続する。動/勤様字とセ候補は未解決で、動セル冒頭は唱歌タを根拠とするE5候補、セは直前音を継続する。篳篥ノと引様末尾の意味、L3.P4/P6の分割は未確認。ノ・末尾は直前音継続の仮説を採用する。明示的く/ノ/末尾/セ候補の同音隣接区間は生成spanを連結し、境界でrelease/attackを再発しない。通常音字は同音でも再発音する作者制御。4行は原資料の列区分であり、息継ぎ句のverified判定ではない。原資料の二返表示は記録するが反復しない。龍笛の右端「初度用之」は本体24点に含めない。

絶対MIDI/オクターブ、A4=430Hz均等律、各主拍点3秒、候補小字の等分割、attack .15秒/release .25秒は作者による音声試作の制御値。篳篥の呂=G4、上=G5、六=D5は採用音域仮説であり実器測定値ではない。工の1932/1894差、笙の旧読解、装飾、息継ぎ、初度・二返の正しい実行、真正の出口・止手は未検証/未実装。末尾releaseを止手と呼ばない。

完全verified演奏イベント数0、必要分母未確定、strict読解はBLOCKED_PUBLIC_EVIDENCEを維持する。本人80点評価・製品受入はUNEVALUATEDであり代理PASSしない。本人試聴を独立開発の停止条件にはしない。音源は検証保存用とし、求められたときに提供する。
