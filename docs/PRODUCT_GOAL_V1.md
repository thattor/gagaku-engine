# PRODUCT_GOAL_V1 — 固定ゴールと製品受入

文書版: `public-handoff-v1` / 2026-10-01。

本書は、既存の `PRODUCT_GOAL_V1` の製品要求を、新しい公開リポジトリで参照できるよう整理したもの。ゴール・権利境界・R/M/A/E/P/Uは変更しない。移行時期・配置・作業順序は実装手段として別文書で扱う。旧文書と本書のファイルhashが一致するとは扱わず、原本由来と本書の版/hashを別々に記録する。

## 固定ゴール

**平調・五常楽急を、笙・龍笛・篳篥の自前生成音源で、雅楽として必要十分に近い音色・音楽的進行により、祭典用途に実用できる形で再生し、ユーザーが再生・編集・複製・配布・商用利用を自由に行える成果として渡す。**

- 演奏経路: `start → program/pass variants → exit_pending → verified exit → verified tomede → ended`。初度・二返・反復・止手と出口の根拠を検証する。
- 最終成果は実音声の三管統合プレイヤーと再生成できる音源。1音、短尺、読解プレビュー、無音の状態機械、調査文書だけで完了にしない。
- 物理モデルによる自前生成を基本とする。オフライン物理レンダリングから自前サンプルバンクを作る方式も可。リアルタイム物理計算は必須でない。
- 実器と区別不能、特定CDの波形や演奏の複製、特定個体の唯一同定、校正済みの実器圧力の再現は求めない。
- 新規の雅楽器演奏、奏者録音、新規実器測定は行わない。生成音のユーザー試聴はこれらに含まれない。
- 初期範囲は本曲・三管・可変尺再生。他曲、打物・絃物、万能シミュレーター、大規模UI拡張は完成の前提にしない。

## R: 権利と制作材料

目的はユーザーの独占権ではなく、他者の権利による利用制約を残さないこと。ユーザーに著作権が発生・帰属することは必須でなく、権利のない成果やオープンデータも許容する。無料公開やオープンデータという表示だけで材料を採用しない。

1. 制作材料は自前生成物、根拠を確認したPD資料、適切に適用されたCC0相当の制約のない資料を候補とする。表示だけで第三者の権利処理まで完了したと推定しない。
2. 他者の保護された録音・サンプル・現代編曲・譜面表現を成果へコピー、混入、変形流用しない。無料、購入済み、商用可、ロイヤリティフリー、CC BY等という理由だけでは採用しない。
3. サンプリング、音源分離、録音を材料にする音色転写・再合成・素材学習、録音から切り出した残響IR等で条件を迂回しない。PD/CC0録音であっても自前物理生成を第三者録音再生へ置き換えない。
4. 曲、譜面の版・注釈・編曲、実演、録音の権利を分けて確認する。古典曲だから現代CDも制作に使えるとは扱わない。
5. 論文・公開解説の事実・数式・モデルの参照と独立実装を、本文・図・コード・音声の複製と区別する。適法な閲覧・試聴、機械分析、制作材料利用は用途を別管理する。
6. Apple Music等の参考曲を、抽出・再録音・DRM回避してモデル入力や自動分析へ渡さない。視聴・分析は実際の権利・規約・アクセス手段に従う。聴けなければ未試聴と記録する。
7. ソフトウェア依存関係は音素材とは別に台帳化し、コード配布と生成音声への条件を個別に確認する。第三者コードを無断転記しない。
8. 実際に制作へ使う全材料について、出典URL/DOI、版・ページ、用途、権利根拠、検証状態、変換過程、artifactとの対応を保存する。`unverified / prohibited` を制作allowlistへ自動昇格しない。

コードと生成音声・譜面データのライセンスは別に管理する。公開repoの作成は既存資産の再ライセンス承認ではない。現時点のライセンス未設定を維持し、選定が必要なら用途と依存関係を整理して所有者へ判断を求める。選定待ちで、独立して進められる実装・検証まで停止しない。公開済みであることだけで自由再利用を保証したと表示しない。

## 完了判定

**`DONE = R AND M AND A AND E AND P AND U`**。
すべて同一release candidate、ソースcommit、入力、artifactに対応する証拠で判定する。未評価はPASSでない。研究評価と製品受入は別記録とする。

### ユーザー試聴の4問

1. 曲の進行・三管の組合せが、今回の五常楽急の用途として受け入れられるか。
2. 各楽器の音色と合奏が、笙・龍笛・篳篥による雅楽として必要十分に近く、用途に使えるか。
3. 保続・手移り・反復・終了に、用途を妨げる機械音・継ぎ目・不自然さがないか。
4. 最終候補を5分以上試聴し、祭典用途に継続使用できるか。

回答は `用途可 / 要修正 / 未評価`。要修正は時刻と問題分類を記録する。FAD、H4/H2、特定録音との距離だけでUを代替しない。追加奏者・新規録音・大規模な知覚実験を前提にしない。

R/M/A/E/Pがすべて完了しUだけ未評価なら `READY_FOR_USER_REVIEW`。実物と4問を提示する。診断音声を聴けるだけの段階をこの状態へ昇格しない。

## 固定するもの・柔軟に変更するもの

- 固定: 本曲、三管、上記の権利・受入・新規測定禁止。変更には所有者の明示承認が必要。
- 柔軟: モデル形式、根拠のある開口面積・管負荷、Q等の音色設計値、演奏制御、オフライン生成、アルゴリズムによる残響・補正、作業順序・分割。rawと加工後の音声は別保存する。
- 研究用Gate本文・閾値、過去のFAIL/UNVALIDATED/UNVERIFIEDと音声を保存する。製品採用を物理同定成功と称さない。実測値・文献値・仮定・音色設計値を分類する。
- 新規測定が必要な実器同定経路は停止する。ただしQの未同定だけで本製品全体を停止しない。許容手段で固定条件を達成する経路を検討する。
- 作業予算を使い切った、資料が一度見つからなかった、という理由だけで全体不可能と断定しない。制約変更が不可欠な場合は証拠・未達条件・代替検討を示して判断を求める。

## 収束方法

不足を1点特定→反証可能な仮説→既存資料の確認→足りない根拠だけ追加探索→変更1点→同じ入力・レベル・検査で比較→採否理由を保存する。モデル比較では制御を、制御比較ではモデルを固定する。調整に使わない検証区間も残す。

候補評価前に区間・演奏条件・検査方法を固定する。結果に合わせて閾値を緩めない。測定器のバグ修正は旧結果を残し、根拠と再検査を記録する。同じ不足の初回予算は最大3サイクル。延長には新しい仮説・根拠・終了条件を記録し、Q探索や文献収集だけを無期限に続けない。

進捗と方法は別文書・Issueへ更新する。本書を進捗に合わせて書き換えない。
